# ASTRA

Interplanetary Survival Guide: Martian Map — NASA Space Apps Challenge 2026.

ASTRA is a hyperlocal Mars excursion planner. Ask it for a site (by text or
voice) and it flies the globe there, reads the nearest live weather, presents a
sourced survival briefing, and plans a slope-limited traverse with an elevation
profile. Replies are spoken with a neural voice.

## What works

- **Mars globe** — CesiumJS with the NASA Mars Trek Viking MDIM 2.1 mosaic;
  fly-to Gale Crater, Jezero Crater, and Mount Sharp / Aeolis Mons.
- **Live conditions** — Curiosity REMS sol summary with provenance. At Jezero
  the UI labels the Gale station as the nearest live station (3,767 km away).
- **Survival briefing** — curated mission briefing, hazards, science targets,
  landing site, and verified source links. Wording is generated by the agent;
  numbers come from backend tools.
- **Route planning** — A* on the 16 ppd MOLA global DEM with a configurable
  slope limit. Returns distance, ascent/descent, max/mean grade, simulated scout
  ETA, and a downsampled elevation profile.
- **Voice** — browser speech recognition for input (Chrome/Edge), `edge-tts`
  for spoken replies with a voice toggle. Text input always works.
- **Command/ack channel** — UI map actions are only reported as done after the
  frontend acknowledges the WebSocket command.

## Stack

- `backend/` — FastAPI (Python 3.11, uv), Agno + Groq commander, deterministic
  DEM/route services, REMS client, edge-tts.
- `frontend/` — Vite + React + TypeScript, CesiumJS, Zod, Zustand, Tailwind.

## Run (dev)

### 0. Environment

```sh
cp .env.example backend/.env
# set GROQ_API_KEY in backend/.env (required for chat)
# NASA_API_KEY is optional; the demo data sources are keyless
```

### 1. MOLA DEM (once, ~33 MB)

The 16 ppd MOLA GeoTIFF is not committed:

```sh
mkdir -p backend/data/dem
curl -L --retry 3 -o backend/data/dem/megt90n000eb.img \
  https://pds-geosciences.wustl.edu/mgs/mgs-m-mola-5-megdr-l3-v1/mgsl_300x/meg016/megt90n000eb.img
```

Set `MOLA_DEM_PATH` in `backend/.env` only if you store it elsewhere.

### 2. Backend

```sh
cd backend
uv sync
uv run fastapi dev app/main.py
```

(`.venv/bin/fastapi dev app/main.py` works too.) Health check:
`GET http://localhost:8000/health`.

### 3. Frontend

```sh
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`. Vite proxies `/api` and `/ws` to port 8000.

## Demo script

1. **Fly + weather** — "Take me to Gale Crater and tell me the weather."
   Fly-to completes, then the conditions card shows sol, air/ground temps,
   pressure, opacity, UV, and sunrise/sunset.
2. **Briefing** — "Give me the survival briefing for Gale Crater."
   Briefing panel plus a landing-site marker (Bradbury Landing).
3. **Route** — "Plan a 10 degree route from Gale Crater to Mount Sharp."
   Route line, start/end pins, auto-framed camera, stats, and elevation chart.
   Ask for 5 degrees to see the longer detour; a 3,767 km request is rejected
   (400 km limit).
4. **Voice** — toggle **Voice** in the chat header; the mic button transcribes.
5. **Jezero** — "What is the weather at Jezero?" — no fly, nearest-station
   labeling, Octavia E. Butler Landing marker via the briefing.

## Data and provenance

Every displayed measurement carries `{mission, instrument, source_url,
retrieved_at}` from the backend. Key sources:

- Mars Trek Viking mosaic — NASA/JPL Mars Trek.
- MOLA MEGDR 16 ppd — NASA PDS Geosciences (MGS MOLA).
- REMS weather — Curiosity, NASA/JPL (outreach purposes only).
- Mission overviews — NASA Science (MSL, Mars 2020).
- Landing site names — IAU / USGS Gazetteer of Planetary Nomenclature.

Demo interpretation notes are labeled curated or simulated; the model never
computes measurements.

## Known limitations

- MOLA 16 ppd is ~3.7 km/pixel, so route grades are regional estimates, not
  trafficability. ETA assumes a 1 m/s scout and is simulated.
- Live weather is Gale-only; Jezero reuses the Gale station with a distance
  label. There is no radiation, dust-storm forecast, or habitat model.
- Science targets are curated and unpositioned; no thermal/HiRISE overlays yet.
- The traverse is a preview; no rover model is animated.
